# 南非（ZAF）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `govza` | 南非政府门户文档库：政府公报镜像（Gazette 公告，行内自带公报号与公告号）+ 法案（Acts）+ 议案（Bills / Draft bills）+ 宪法及修正 + 绿皮书 / 白皮书 | [www.gov.za/document](https://www.gov.za/document)（日期过滤检索页 + 文档详情页 + PDF 直链，全部免 key） | [govza-zh.md](./govza-zh.md) |

制度背景一句话：南非《政府公报》（Government Gazette，南非语 Staatskoerant）的法定出版者是**政府印刷局**（Government Printing Works，缩写 GPW，内政部辖下），约 2012/13 年起电子版与印刷版同等法律效力；gov.za 是政府传播与信息系统（GCIS）运营的官方门户，镜像公报内容并加挂其他政策文档。GPW 自有门户（gpwonline.co.za / efiling.gpwonline.co.za）2026-10-10 实测无可用机读通道（eFiling 连接失败、公报库旧路径 404、信息站无 PDF 直链），故本仓从 gov.za 收。

## 1b. 三结构现状

- **时间序列**：govza 源承担（一行一个出台事件，按门户文档日组织；公报类公告约自 1999/2000 年起有收录，更早年份为白皮书等散档）。
- **决策过程**：记缺（议会过程源未开；公报公告行的"Comment by"评论截止日期随 meta 收录，可作过程侧线索）。
- **版本序列**：记缺（门户一文档一记录，无原生修订谱系；法案的修订关系要靠分析阶段从标题与公报号建图）。

## 2. 共享访问准备

- 无需任何 key；标准 HTTP GET，无会话、无 cookie。
- 目录约定：数据根下每国一个 `{ISO3}_policy/`，原始文件在 `01_raw/govza/{年}/{月}/{slug}/`，纯文本在 `02_cleaned/`。
- 命令习惯（在仓库根）：`python cli.py collect --country zaf --source govza window=起:止`，增量用 `sync=1`，试算用 `--dry-run`。
- 限速节奏：gov.za 无公开限额，但响应偏慢（单页 2–3 秒，2026-10-10 实测）；`--delay 2:4` 是温和默认。大批量回填宜小批量长间隔（防累计封锁），封锁期间零请求、次日温和收口。
