> 数据快照日期：2026-09-18。文中状态码、字节规模、行数与日期字段均为实测真实值（可重放复核）；账本内计数以 **2000-01-01..2026-09-17 全量回填**（2026-09-16..18 运行）为准（§5）。

## 1. 源概览

### 1.1 制度背景：拉脱维亚的官方公布媒介是什么

拉脱维亚的官方出版物是**《Latvijas Vēstnesis》**（"拉脱维亚使者/公报"，门户 vestnesis.lv）。其法律地位由《Oficiālo publikāciju un tiesiskās informācijas likums》（官方出版物与法律信息法）§2(1) 直接定义：官方出版物"Latvijas Vēstnesis"是拉脱维亚共和国的官方出版物，其中刊载的信息即官方公布（2026-09-16 读法律原文核对）。出版方为国有公司 VSIA "Latvijas Vēstnesis"；自 **2013-01-01** 起公报为纯电子出版（此前兼纸质）。公报自 **1993-02-25**（独立恢复后首刊）起连续出版至今（2026-09-16 实测：页面内置的全部出版日期表首日为 1993-02-25，当日刊编号 178）。

同一家出版方还运营**现行法规库 likumi.lv**（"拉脱维亚共和国法规"，约 2001 年建库）：收录现行有效文本与编纂版本，属信息性服务，法律效力仍在公报原件。两站**共用同一套文档编号**并互相链接（实测：宪法 id 57980、2024 年修订法 id 352471 双站同号互链）。

**本源的采集路径由这两个网站分工**：

- **枚举（某天公布了什么）走 likumi.lv**。公报网站没有按日期的目录页，而 likumi.lv 提供按**公布日期**编址的清单页：一天一页，服务端直出（无需浏览器），每行自带完整书目字段；空刊日（周末与无刊日）返回干净的空单。清单页 1995 年起有数据（2026-09-16 对 1995-05-04 实测 3 行；更早年代未验证，见 §8）。
- **文档本体（正式公布原文）走 vestnesis.lv**。凭文档编号访问 `/ta/id/{id}`：2012 年前后的老文档直接返回文档页；新文档经服务器跳转到达规范地址 `/op/{出版年}/{期号}.{期内部号}`（如 `https://www.vestnesis.lv/op/2024/107.1`，2026-09-16 实测）。文档页含书目块（发布者/类型/采纳日/OP 号）、完整公布引用、指向 likumi.lv 的互链与**内嵌正文**。

**收录范围**：likumi.lv 清单收录公报刊载的法规类条目——议会法律（likums）、内阁与总理文件、总统令（rīkojums）、中央选举委员会决定（lēmums）、部委条例（noteikumi）以及地方自治体条例（saistošie noteikumi）。非法规类公报内容（公告、拍卖、招聘启事等 paziņojumi）不在清单中（实测：公报某期含非法规条目时，清单的期内部号从中间开始，如 2024-12-19 期 248 从 .3 起连续收录 76 条，缺失的 .1/.2 为非法规公布项）。本源默认采集**国家级**（scope=state：清单发布者与文档页发布者两级过滤地方自治体），地方条例仍在清单中，放开口径即可补采。

**文档形状**：每份文档一份公报原文页（as-published 快照——公布时定格，不随后续修订变化）。现行有效文本与历史版本在 likumi.lv 有原生版本序列（"Redakcija uz" 版本选择），但其版本日期页路径被该站 robots.txt 明令禁止抓取，本源不收（§8）。

### 1.2 与欧盟法的关系

1. **转化立法——在本源内，正常逐条抓取。** 拉脱维亚把 EU 指令转化为国内法用的是普通 likums/noteikumi，与本国产出同通道。
2. **直接生效的 EU 条例——不在本源。** 需要 EU 条例原文须去《欧盟官方公报》，超出本源范围。
3. 官方译文版：likumi.lv 为部分法律提供英文版（URL 前缀 `/en/`），公报侧无译文；本源语料保持拉脱维亚语单语（§8）。

| 项 | 说明 |

| API key | **不需要**，`.env` 无需任何条目 |
| 会话 | 无（两站全部端点无状态 GET；新文档的服务器跳转由传输层自动跟随，2026-09-16 连续数十请求实测） |
| 字符编码 | 两站均 UTF-8 |

| 空窗口行为 | 无刊日/周末 = HTTP 200 空单（页面无文档清单标记），非故障 |

## 3. 抓什么：任务类型清单

每种任务 = 一次下载 + 一次解析。共 **2 种**：

| 任务类型 | 请求什么 | 产出什么 |
|---|---|---|
| `vestnesis_list`（种子，逐日一个） | GET `likumi.lv/ta/jaunakie/publiceti/{年}/{月}/{日}/`（公布日清单） | 解析结果行 → 每行一个 `vestnesis_doc` 种子（携带文档编号、公布日、生效日、文号、完整标题等行内字段）；按 scope 过滤；空单 → 合法空产出；**完整消费（有果无果一律）推进游标 `vestnesis_last_date`**（账本里"已完整消费到哪一天"的进度标记，§7） |
| `vestnesis_doc`（每文档一个） | GET `vestnesis.lv/ta/id/{文档编号}`（新文档自动跟随跳转到 /op/ 规范地址） | **一次请求双产出**：① 文档记录入账（书目字段全部来自文档页，§4）；② 响应字节 **gzip 压缩后**落盘为文档主文件 `doc.html.gz`（解压即源站原页），框架把它挂回文档账（路径/字节校验和/格式/采集时间） |

任务链：`vestnesis_list × 每天 → vestnesis_doc × 每行`。

命令行参数（key=value 形式）：

```
window=FROM:TO    闭区间日期窗口，如 2024-06-03:2024-06-05（必填，或改用 sync=1）
sync=1            增量：起点 = 游标 vestnesis_last_date 次日，终点 = 昨天
scope=state       采集范围：state = 仅国家级（默认，过滤地方自治体条例）；
                  all = 全部（含地方，改口径自动补抓、无需清库）
```

**窗口按"公布日期"**：清单页按公布日编址，账本 `publication_date` 也是公布日——抓取轴与研究轴一致，无滞后换算。

## 4. 数据落到哪

**零领域表**（扁平文档型路径，同德国 BGBl / 西班牙 BOE）：本源采集单元是公布事件（as-published 文本一次定格），一个文档 = documents 一行。文档间的修订关系（如标题自带的"Grozījumi … likumā"修订字样、likumi 页的修订关联）是**字段**不是实体，随源照收进 meta（建图留给分析阶段）。

一切研究字段进 `documents` 一张表：

| 列 | 内容 |
|---|---|
| `doc_id` | `LVA_{公布日YYYYMMDD}_{hash8(source_url)}` |
| `title` | 完整题名（清单行标题为权威——新文档页标题有省略号截断，如"Grozījumi Komercdarbības atbalsta kontroles… "，2026-09-16 实测） |
| `publication_date` | **公布日**（Publicēts 引用中的 Latvijas Vēstnesis 日期，如 2024-06-04）；研究时间轴主日期 |
| `issuing_authority` | 发布者（Izdevējs，如 `Saeima` / `Ministru kabinets`） |
| `source_url` | `https://www.vestnesis.lv/ta/id/{文档编号}`——全年代通用、无一次性参数、完全可重建（新文档的 /op/ 规范地址入 meta 备查） |
| `raw_format` / `language` | `html` / `lav`（拉脱维亚语；英文译文版不设通道，见 §8） |
| `doc_type` | 由 Veids（类型原词）映射的受控类型（下表）；原词永存 meta |
| `entity_ref` | NULL（扁平国家） |
| `meta` | 见下 |

**meta 字段**（原生字段无损收，全字符串）：`doc_id_src`（两站通用文档编号）、`op_url`（新文档 /op/ 规范地址，如 `https://www.vestnesis.lv/op/2024/107.1`；老文档无）、`likumi_url`（现行文本页链接 `https://www.likumi.lv/ta/id/{id}`）、`native_type`（Veids 原词）、`dokumenta_nr`（文号 Numurs，可选）、**`pienemts`（采纳日）**、**`stajas_speka`（生效日，可选）**、`zaude_speku`（失效日，可选——与 statuss 同为源站**活视图快照**，会随源站维护变化）、`statuss`（效力状态原词：spēkā esošs 在效 / zaudējis spēku 失效 / vēl nav spēkā 未生效）、`publicets_raw`（公布引用原文串，可含第二公布媒介 Ziņotājs——议会与内阁法刊汇编，如 `Latvijas Vēstnesis, 68, 04.05.1995.; Latvijas Republikas Saeimas un Ministru Kabineta Ziņotājs, 11, 08.06.1995.`）、`publicets_nr`（公报期号）、`op_numurs`（`{年}/{期}.{期内部号}`，如 `2024/107.1`；1995 代无此号）、`scope_slice`（state/all）、`list_row_title`（清单行完整标题，恒存）。

**doc_type 映射**（原生优先：Veids 原词永存 meta，映射只是一层受控别名；跨国可比的统一类型学不在采集层做）：

| Veids（拉脱维亚语原词） | doc_type |
|---|---|
| likums | STATUTE（法律；宪法 Satversme 的类型原词亦为 likums，原词照存） |
| noteikumi | REGULATION（内阁/部委条例） |
| rīkojums | ORDER（总统令/总理令） |
| lēmums | DECREE（决定，如中央选举委员会） |
| ziņojums（informatīvais ziņojums 通告类）与其余未见形状 | OTHER |

文件落点（"一项政策一个文件夹"，年/日双层分片）：

```
{data_root}/LVA_policy/
├── state.db
├── failures/
└── 01_raw/vestnesis/
    └── 2024/D20240604/                       ← 年 = 公布年；日 = 公布日
        └── 352471/                           ← 一份文档一个文件夹（文档编号命名）
            └── doc.html.gz                   ← 公报文档页响应字节 gzip 压缩（文档主文件）
```

- `doc.html.gz` 是文档主文件（唯一挂 doc_id 的文件，账本 local_path 指向它）；内容 = 公报页原样字节的 gzip 压缩，`gunzip` 后与源站当前响应逐字节一致；字节校验和按**落盘（压缩后）字节**计算。压缩是体积考虑：公报页正文只占约 10%，其余为每页重复的全站导航（实测 2026-09-16：原页 274–400 KB，压缩后 40–60 KB）。
- 元数据不落单独文件，全部在账本 meta。正文抽取（从 HTML 提纯文本）归规范化阶段，届时解压即得原页。

## 7. 更新与增量

- **游标**：`vestnesis_last_date`。清单任务完整消费自己那一天就把游标推到该日——200 且解析完成（有果无果一律）都算完整消费；中途崩溃该日不推，下次自愈。
- **sync 终点取昨天、不取今天**：当日刊可能尚未发布或清单未更新；"今日尚无"与"当日无刊"在接口上同形（空单），为杜绝误判，增量默认只到昨天。
- **抓的是快照，不设重开**：公布文本与书目字段一次定格，同窗口重复运行安全（任务确定性去重，已抓直接跳过、零请求）。效力状态与失效日是 likumi 活视图，记录抓取当日状态；跟踪修订需按新窗口重扫（机制与既有枚举源一致，本源暂未设周期任务）。
- 往更早日期回填会把游标往回带，下次 sync 幂等重扫（无害，与既有判例一致）。现状即此例：全量回填后的修复补扫把游标带回 2004-01-29（最后重扫的旧日期），此后每次 sync 从该日 +1 起在入队层本地去重（零网络）、只抓真正的新增日，队尾完成即把游标推回当前。清单覆盖自 1995 年起有实证（1995-05-04 实测 3 行；更早未验证，§8）。

## 8. 已知边界与缺口

| 缺口 | 说明 |
|---|---|
| **版本序列（redakcijas）不收** | likumi.lv 有原生版本序列（现行文本各编纂版本，"Redakcija uz" 选择器实证）；但版本日期页路径被该站 robots.txt 明令禁止（`Disallow: /*/redakcijas-datums/`）。本源定位是公报 as-published 时间序列，版本序列另立源再议 |
| **1995–1999 清单可用、2000 年前未验** | 清单对 1995-05-04 有数据（3 行实测）；本库回填自 2000-01-01 起（用户口径）。2000 年前是"无刊/无数据"还是"清单未及"未探；公报纸本 1993-02-25 起连续。扩到清单起点另议 |
| **地方自治体条例默认不收** | scope=state 默认过滤（按发布者名单式判定：novada/pilsētas dome 系）；`scope=all` 一键放开，改口径自动补抓 |
| **官方译文版不设通道** | likumi.lv 部分法律有英文版（URL 前缀 /en/，2026-09-16 实测样本）；公报侧无译文。语料保持拉脱维亚语单语 |
| **公告类公报内容不在清单** | likumi 清单只收法规（tiesību akti）；公报同期刊载的公告/拍卖/招聘等（paziņojumi）不进清单——表现为期内部号不从 .1 开始（2024-12-19 实测）。如需公告类另立通道 |
| **效力状态是时点快照** | statuss / zaude_speku / stajas_speka 抓的是当天值，不自动更新（§7） |
| **跨下载字节比对受页面日历影响** | 文档页侧栏的"日期导航表"随每期新刊自动追加日期串（2026-09-18 实测解剖：存储页与现页唯一差异即此，去标签正文完全一致）——跨下载字节一致性只在同一日历窗口内成立；file_hash 按**落盘字节**计算，档案完整性不受影响，正文级比对请用去标签文本 |
| **新文档页标题截断** | 公报文档页标题按宽度截断加省略号（2026-09-16 实测）；权威标题取清单行完整标题（恒存 meta.list_row_title） |
| **文档页含全站导航，gzip 压缩存储** | 原页 274–400 KB 中正文仅约 10%；主文件为 gzip 压缩的原样字节（解压即源站原页），纯正文抽取归规范化阶段 |
