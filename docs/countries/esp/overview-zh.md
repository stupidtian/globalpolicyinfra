# 西班牙（ESP）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）；九节写作结构见 [_template-zh.md](../_template-zh.md)。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `boe` | 国家官方公报（BOE）第 I 部：法律、组织法、王室令-法、立法王室令、王室令、部委令——西班牙国家层级的全部成品规范（部委令为主体，法律在颁布日刊出） | boe.es 官方开放数据 API（免 key、无会话、日期直构 URL、XML 一条式详情含全文） | [boe-zh.md](./boe-zh.md) |

## 1b. 三种数据结构现状

- **时间序列**：✅ 由 `boe` 源承担——按日公报全序列（1961 年起档案在线），每条带制定日 / 刊出日 / 生效日三个日期。
- **决策过程**：未收——国会两院（Congreso / Senado）的立法过程系统未开，记缺。
- **版本序列**：未收——现行编纂文本（texto consolidado）的官方机器通道已确认存在（2026-09-01 实测），需要时另立源，清单见 [boe-zh.md](./boe-zh.md) §9。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `python cli.py init` 配置，或 `POLICY_DATA_ROOT` 环境变量；西班牙数据落在 `{data_root}/ESP_policy/` |
| 密钥 | **无需任何 key**，`.env` 不需要条目 |
| 通用命令习惯 | `collect`（key=value 传参）/ `status` / `export` / `requeue` / `reset`，全部在仓库根目录 `python cli.py` 运行 |
| 节奏 | 框架统一限速（请求间隔 0.5–1 秒随机）+ 错误三分法重试；BOE 每日一摘要 + 第 I 部逐条详情，典型工作日几十个请求 |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 国会立法过程（法案、辩论、表决） | Congreso / Senado 两院系统，未开工 |
| 自治区官方公报（DOGC、BOPV 等 17 个大区公报） | 地方层，不在国家公报内；国家公报第 I 部**偶发**大区立法（如马德里法律，2026-08-29 实测 2 条），默认按来源字段排除、参数可放宽（见 boe-zh.md §3），大区公报本体未开工 |
| EU 法原文 | 欧盟条例直接生效、不经 BOE 刊发；需要时另立 EU 源 |
| 现行编纂文本（texto consolidado） | 机器通道已确认（见 1b），未开工 |
| 公报第 II / IV / V 部（人事、司法管理、公告） | 不在采集目标内；第 III 部（机构决议类）经参数可扩，默认未收 |
