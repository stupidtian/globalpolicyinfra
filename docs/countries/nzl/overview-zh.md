# 新西兰(New Zealand,NZL)数据源总览

> 一个源一个文件:本文件只做总览与共享信息,各源细节见对应文件。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `gazette` | 新西兰官方公报(New Zealand Gazette / Te Kāhiti o Aotearoa)的通知——政府公报自 1841 年创刊,是法定通知的官方刊登之地,工作日连续出版 | DigitalNZ API(新西兰国家图书馆的全国数字藏品聚合接口,免密钥)——公报办公室把通知的元数据与全文交给了这个聚合平台 | [gazette-zh.md](./gazette-zh.md) |
| `legislation`(在建) | 议会法律顾问办公室(Parliamentary Counsel Office,PCO)的法规库——法案(Act)、次级立法(secondary legislation,依法律授权制定的法规文件)的权威现行库,原生版本序列 | 新西兰法规 API(`api.legislation.govt.nz/v0`,需免费注册的 API 密钥;密钥申请页面 legislation.govt.nz 的 Legislation data / developer API 一节) | 施工中,密钥到位后补文件 |

两层的分工:gazette 收"**什么时候公布了什么**"(公布事件,时间序列主轴);legislation 收"**一部法规有哪些版本文本**"(版本序列主轴)。同一次级立法会在两边各出现一份——公报里是公布时的快照,法规库里是可更新的现行文本——两者靠各自的原生编号对应,本仓库不做跨源合并。

## 2. 三结构现状

- **时间序列**:gazette 源承担,2000-01-01 至 2026-10-11 全量回填完成(2026-10-14 对账:207,289 条,逐年与聚合接口全等;2000 年 9,271 条、2009 年 10,389 条为峰值、2024 年 6,362 条;1999 年及以前聚合平台未收录)。
- **决策过程**:记缺(议会过程数据在 Parliament NZ,不在本仓库范围)。
- **版本序列**:legislation 源承担(在建)——法规 API 的 work → version → format 三层模型原生给出每部法规的全部文本版本。

## 3. 共享访问准备

- 数据目录:按全局配置的数据根,国家目录为 `NZL_policy/`。
- 密钥:gazette 源**无需密钥**(DigitalNZ API 匿名可查;若日后需要更高配额可在 digitalnz.org 免费注册,填入 `.env` 即可)。legislation 源需要免费 API 密钥(每天 10,000 次请求,新西兰时间午夜重置),在 `.env` 中配置 `NZL_LEGISLATION_API_KEY`。
- 限速习惯:两源都不公布匿名访问的速率上限,建议 `--delay 2:4`(每请求间隔 2–4 秒)起步,观察无告警再收紧。
- 语言:英语为主体;个别公报通知为毛利语(te reo Māori)或双语。语言字段照源站原样收录,源未标注则留空,不做猜测与翻译。
