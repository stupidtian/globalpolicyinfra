> 数据快照日期:2026-09-08。文中条目计数、字节数与字段值均为当日对源站的实测真实值(样本已存档,可重放复核);账本内计数在首次真实运行后补记(§5 末行)。
> 阅读前提:了解 `python cli.py` 用法即可,不需要读代码。斯洛伐克全部源总览见 [overview-zh.md](./overview-zh.md)。

## 1. 源概览

### 1.1 制度背景:Zbierka zákonov 是什么、装了谁的产出

**Slov-Lex**(slov-lex.sk)是斯洛伐克**司法部**运营的官方法律门户,聚合法规、立法过程、判例与欧盟法。本源采集其中的 **Zbierka zákonov**(《法律汇编》,下称 ZZ)——斯洛伐克**国家层级一切规范文件的法定公布媒介**:规范文件只有在此公布才生效(对第三人具有效力)。

现行依据是 **400/2015 Z. z. 《法规制定与法律汇编法》**(取代 1993 年的 1/1993 号法,2016 年起施行):

- **§12**:ZZ 的**电子版经 Slov-Lex 免费发布,与纸质版同等法律效力**——即本源抓的就是官报本体,不是转载;
- **§19**:规范自公布日(declared day)起生效(除非另有规定),原则上公布后第 15 日生效;
- **§22**:每年 1 月 1 日起连续编号(如 `126/2026 Z. z.` = 2026 年第 126 号),刊头载公布日期,按**分册(čiastka)**组织;
- **§14**:同一法规被多次修订后,司法部可在电子版中公布**整合版**(konsolidované znenie,合并修订的完整现行文本)——整合版也是官方刊登物(本源暂不采集,见 §8)。

**语料范围**(2026-09-08 实测):检索库共 **26,562** 条,时间跨度 **1918–2026**——1918 年起的捷克斯洛伐克时期文本也在库中(1993 年斯洛伐克独立前用 `Zb.` 编号,如 `49/1918 Zb.`《货币法》),1993 年起用 `Z. z.` 编号。年度规模参考:1993 年 342 条(其中法律 121 部)、2025 年 423 条、法律(Zákon)全库 6,033 部。

**收录文种**(检索库 `typPredp` 字段,2026-09-08 采样 7 种已证实):Zákon(法律)、Nariadenie vlády(政府条例)、Vyhláška(部委规章)、Opatrenie(措施)、Oznámenie(通告)、Uznesenie(政府决议)、Rozhodnutie(决定)。其中通告类(Oznámenie,如集体合同公告、国际条约告示)占比很高——这是斯洛伐克的特点:2021 年之前部分此类文件登在另一份公报(Vestník)里,现行制度下全部进 ZZ(见 §8 Vestník 条目)。

**不在本源里的东西**:判例(Ústavný súd 宪法法院 / NSS 最高行政法院,门户另有专区)、议会立法过程(eLegislatíva 模块)、欧盟法原文(Právo EÚ 模块)、以及**整合版全文**(§8)。自治体法规不在 ZZ。

### 1.2 一个关键口径:本源抓"公布原文",不抓"现行整合版"

Slov-Lex 对每部法规同时提供两种文本:**公布原文**(首次刊登的文本,永不变化)与**整合版**(随修订持续更新)。检索接口返回的正文链接**指向该法规当前最新的整合版**(2026-09-08 实测:1993 年 16 号法,历经多次修订,检索给出的链接尾随日期是 2017-06-01——最新整合版的生效日;而其 1993 年原文仍可按 `…/19930101.html` 直取)。

**对新发布的法规两者是同一份**(还没有任何修订)——本源的采集语义因此定为:**抓"发现时刻"的原文快照**。对增量与新近窗口,这就是公布原文;对很久以前的旧窗口重抓,若某法已被整合,取到的是发现时刻的整合版快照(链接与内容自洽、如实入账,详见 §7 的"指针漂移"说明)。

### 1.3 数据通道:检索 JSON 接口 + 静态正文页(免 key、无会话、无浏览器)

**① 检索接口**(枚举的唯一入口,门户前端同款):

```
GET https://api-gateway.slov-lex.sk/vyhladavanie/predpisZbierky/rozsirene?rows=100&start={偏移}
```

- 响应为 Solr 风格 JSON:`{"numFound": 总数, "start": 偏移, "docs": [条目…]}`,默认按公布日(`vyhlaseny`)倒序;
- 条目字段(2026-09-08 实测全集):`iri`(正文路径,见 ②)、`vyhlaseny`(公布日)、`typPredp` / `typPredp_value`(文种机器名/斯语原词)、`rocnik`(年份)、`nazov`(标题)、`cislo`(编号,如 `126/2026 Z. z.`)、`ucinnyOd`(生效起)、`ucinnyDo`(生效止,有条件出现)、`zodpovedajucaUcinnost`(所指版本的基准日)、`nadpisy`(节标题,法律类常见);
- **实测有效的参数**:`rows` / `start`(分页)、`q`(全文检索,`*` 可单独使用)、`typPredp`(文种过滤)、`rocnik`(年份过滤)、`sort`(如 `vyhlaseny asc|desc`);**无日期过滤参数**(`fq`、`vyhlasenyOd/Do` 等被静默忽略,2026-09-08 双重复核)——所以日期窗口靠"倒序翻页 + 按公布日截断"实现(§3);
- 免 key、免会话、无csrf。

**② 静态正文页**(一条 = 元数据 + 关系表 + 全文,一站式):

```
GET https://static.slov-lex.sk/static{iri}        →  纯服务端渲染 HTML
GET https://static.slov-lex.sk/pdf/SK/ZZ/{…}.pdf  →  官方 PDF(§4;页内自带链接的前缀失效,此处为实测活地址)
```

`iri` 形如 `/SK/ZZ/2026/126/20260701`——`/SK/ZZ/{年份}/{号}/{版本生效日}`。页面结构(2026-09-08 对真实字节实测):

1. 警示条:**"显示内容仅供参考,具有法律约束力的是 PDF 版"**(因此 PDF 随抓,§4);
2. **元数据表**(`<table id="InfoTable">`):Číslo predpisu(编号)、Názov(标题)、Typ(文种)、**Dátum schválenia(批准日)**、**Dátum vyhlásenia(公布日)**、**Dátum účinnosti od / do(生效起/止)**、**Autor(发布机关,原生精确)**、Právna oblasť(法律领域)、Legislatívny proces(立法过程编号,如 `LP/2026/211`)、Nachádza sa v čiastke(所在分册;2026-07 的页面模板尚无此行、2026-09 已有——解析按标签通用处理,两种形状都兼容);
3. **关系面板**("Vzťahy predpisu"):按关系类型分组的法规引用表(如 "Predpis mení" = 本法修订了哪些法规),行内含编号与门户链接——**修订关系的原始字段证据,随源照收入 meta**;
4. 法规全文(语义化结构:法规号/类型/日期/标题/条款分节)。

**编码注意**(踩过的坑,2026-07 旧库存量数据 57 份全部中招):静态页响应头**不带 charset**——用会按 HTTP 头猜测编码的 HTTP 客户端默认库会退回 Latin-1,斯语变音符号全部变成双重编码乱码(如 `Zbierka zÃ¡konov`)。本源对响应字节**显式按 UTF-8 解码**,问题根除(测试有用乱码字节回归的用例)。

## 3. 抓什么:任务类型清单

每种任务 = 一次下载 + 一次解析。共 **2 种**:

| 任务类型 | 请求什么 | 产出什么 |
|---|---|---|
| `svk_list`(种子,逐页一个) | GET 检索接口(§1.3 ①),`rows=100&start={偏移}&sort=vyhlaseny+desc` | 窗口内条目逐个生成 `svk_pdf`;本页满 100 条且未越过窗口下界 → 生成下一页 `svk_list`(`start+100`);整窗走穿下界 → 推进游标 `slovlex_last_date`(账本里"已完整消费到哪一天"的进度标记,§7);窗口内 0 条 → 合法空产出 |
| `svk_pdf` | GET 官方 PDF(§4 地址规律) | PDF 兄弟文件落盘,并生成 `svk_doc`(携带 pdf_ok 标记);PDF 缺席(404/410,属正常数据)→ 只生成 `svk_doc`,HTML 仍是文档本体,账本不虚记文件 |
| `svk_doc` | GET 静态正文页(§1.3 ②) | 一个文档记录 + HTML 主文件落盘;检索条目字段与页面元数据**交叉校验**(编号/公布日/文种不符 → 按形状突变告警升级,绝不静默) |

任务链:`svk_list × 逐页(倒序翻到窗口下界)→ svk_pdf × 窗口内每条 → svk_doc × 每条`。PDF 任务先行是刻意的:每个任务恰好一个请求,而兄弟文件的路径要写进文档的文件清单——先知道 PDF 在不在,清单才能只说真话。

**为什么倒序翻页**:检索接口无日期过滤参数(§1.3),默认(及显式)按公布日倒序——从最新往回翻,一旦某页最旧条目的公布日早于窗口起点,其后必然全部更早,即停。越过窗口终点的条目(比"到日"更新)跳过、继续翻。

命令行参数(key=value 形式):

```
window=FROM:TO    闭区间日期窗口,如 2026-06-16:2026-07-02(必填,或改用 sync=1)
sync=1            增量:起点 = 游标 slovlex_last_date 次日,终点 = 昨天(为什么不是今天见 §7)
max_docs=200      单次运行入账文档数上限(默认无;翻页计数照常,仅截断文档生成)
```

## 4. 数据落到哪

**零领域表**(扁平文档型路径,同西班牙 BOE / 德国 BGBl / 法国 JORF):公报条目刊出即定、条目即文档本体,语料里没有跨文档的持久实体;条目间的修订/废止引用关系是**字段**不是实体,随源照收进 meta(建图留给分析阶段)。一切研究字段进 `documents` 一张表:

| 列 | 内容 |
|---|---|
| `doc_id` | `SVK_{公布日YYYYMMDD}_{hash8(source_url)}` |
| `title` | 完整题名(如 `Zákon, ktorým sa mení a dopĺňa zákon č. 142/2024 Z. z. …`) |
| `publication_date` | 公布日(Dátum vyhlásenia)——研究时间轴的主日期 |
| `issuing_authority` | 发布机关原生全名(页面 Autor 字段,如 `Národná rada Slovenskej republiky`;部委通告则是对应部委) |
| `source_url` | `https://static.slov-lex.sk/static{iri}.html`——版本化规范地址(尾随版本生效日),可重建、永不漂移 |
| `raw_format` / `language` | `html` / `slk`(斯洛伐克语) |
| `doc_type` | 由 typPredp 映射的受控类型(下表);斯语原词永存 meta |
| `entity_ref` | NULL(扁平国家) |
| `meta` | 见下 |

**meta 字段**(原生字段无损收,全字符串):`typ_predp` + `typ_predp_value`(文种机器名/斯语原词)、`cislo`(编号)、`rocnik`(年份)、**`ucinny_od` / `ucinny_do`(生效起/止)**、`zodpovedajuca_ucinnost`(所指版本基准日)、`verzia`(iri 尾随版本日)、**`datum_schvalenia`(批准日)**、**`datum_vyhlasenia`(公布日)**、**`datum_ucinnosti_od` / `datum_ucinnosti_do`(生效起/止,页面口径)**、`autor`(发布机关)、`ciastka`(分册,新模板字段,旧页面如实缺省)、`pravna_oblast`(法律领域,多值连接)、`legislativny_proces`(立法过程编号;通告类没有,如实缺省)、`vztahy`(关系面板引用,格式 `关系类型:编号;…`)、`nadpisy`(节标题)、`files`(文件清单)。

**效力状态的读法**(全部原生日期,推导零猜测):`ucinny_do` 空 = 长期现行;`ucinny_do` 为未来日期 = 现行有限期(日落条款,实测样本 168/2026 Z. z. 生效止 2027-12-31);`zodpovedajuca_ucinnost` = `ucinny_do` 且早于今天 = 已废止(实测样本 15/1993:生效止 2001-12-31、基准日同为 2001-12-31,而现行法基准日恒为请求当天)。

**doc_type 映射**(原生优先:typPredp 机器名与斯语原词永存 meta,映射只是一层受控别名;未见过的文种一律 OTHER、原生词照存,重打标零成本):

| typPredp(机器名) | 斯语原词 | doc_type |
|---|---|---|
| Zakon | Zákon(法律) | STATUTE |
| NariadenieVlady | Nariadenie vlády(政府条例) | REGULATION |
| Vyhlaska | Vyhláška(部委规章) | DECREE |
| Opatrenie | Opatrenie(措施) | SECONDARY_LEGISLATION |
| Oznamenie / Rozhodnutie | Oznámenie(通告)/ Rozhodnutie(决定) | ADMINISTRATIVE_NOTICE |
| Uznesenie | Uznesenie(政府决议) | OTHER |
| 其余 | — | OTHER |

**PDF 兄弟文件**:官方 PDF 地址规律已下载级验证(2026-09-08 两样本):`https://static.slov-lex.sk/pdf/SK/ZZ/{年份}/{号}/ZZ_{年份}_{号}_{版本日}.pdf`。**一个坑**:页面里自带的 PDF 链接前缀(`/static/pdf/…`)按页面原点拼接是失效的(404),正确地址须把前缀换成 `https://static.slov-lex.sk/pdf/`——路径骨架与版本日均取自页面原生链接,仅前缀修正(已在实现与测试中固化)。每个文档抓 HTML 主文件 + PDF 兄弟文件(HTML 挂账本主路径,PDF 路径入 meta.files——页面明示 PDF 才是具法律约束力的定版)。

## 7. 更新与增量

- **游标**:`slovlex_last_date`。`svk_list` 倒序翻页**走穿窗口下界**(该日及以后的条目全部看遍)才把游标推到窗口终点;中途崩溃不推,下次自愈。
- **sync 终点取昨天、不取今天**:ZZ 当日条目随公布节奏在一天内陆续出现,当天可能尚未出全——为杜绝把"尚未出全"当"当日无刊",增量默认只到昨天。确需当天数据:显式跑 `window=…:今天`。
- **公布原文不变、不设重开**:同窗口重复运行安全(任务确定性去重,已抓直接跳过、零请求)。
- **指针漂移(如实声明)**:检索接口对**已被修订整合的旧法**会改指向最新整合版(§1.2)。首次窗口/增量抓到的一律是原文;很久之后重抓旧窗口,若窗口内某法已被整合,会取到该时刻的整合版快照——链接与内容自洽、如实入账为新文档。持续跟踪整合版需按新窗口身份周期性重扫(本源暂不启用)。
- **补漏保险**:若某日公布极晚(公布日当天未入库、次日才出现),按公布日倒序翻页天然会在下一次 sync 时于更早页命中(增量起点是游标次日,翻页从最新开始,会经过该条)。

## 8. 已知边界与缺口

| 缺口 | 说明 |
|---|---|
| **整合版不抓** | 检修合并后的现行文本(konsolidované znenie,法定官方产物)不在采集范围;版本序列研究需要时另立通道(门户的版本切换接口存在、机器通道未探明) |
| **附件 PDF 不抓** | 部分法规带附件文件(prílohy,13/57 页面带附件链接);主 PDF 抓、附件记缺 |
| **判例不在本源** | 宪法法院/最高行政法院判例是门户另一专区,不采 |
| **议会过程不采** | 立法过程编号(legislativny_proces)入 meta 保留挂点;过程数据另属 eLegislatíva 模块 |
| **欧盟法不在本源** | 门户 Právo EÚ 模块;需要 EU 条例原文去《欧盟官方公报》 |
| **历史公报 Vestník 不采** | 2021 年前部分政府文件登《政府公报》(Vestník vlády SR,内政部主持);现行制度下已并入 ZZ,门户仅存档案模块、导航无入口。历史 Vestník 数据记缺,需要时另立 |
| **1918–1992 段属回填议题** | 捷克斯洛伐克时期文本在库可抓,但同窗口语义下旧法多已被整合(§7 指针漂移),历史回填需版本通道配套——另行规划 |
| **效力状态是时点快照** | 生效止/基准日记录抓取时刻的值;判定规则见 §4 |
| **出口选择性拒答** | 源站应用层防火墙按出口拒(§2);全量 404 时先换出口再怀疑源站 |
| **编码坑** | 正文响应头无 charset,必须显式 UTF-8 解码(§1.3);已有乱码回归测试用例 |
| **页面 PDF 链接前缀失效** | 页面 href 写 `/static/pdf/…`,按原点拼接 404;正确地址见 §4(下载级验证) |
