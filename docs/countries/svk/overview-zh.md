## 1b. 三结构现状

- **时间序列**(必答):已覆盖——每条公报刊登记一行(公布日为时间轴主日期),批准日/公布日/生效起止四类原生日期分列全收;缺项如实留空(如通告类无批准日)。
- **决策过程**:记缺——议会立法过程在门户 eLegislatíva 模块,未采;立法过程编号(legislativny_proces)已随条目入 meta,未来开设过程源即有挂点。
- **版本序列**:记缺(部分)——本源抓公布原文;官方整合版(konsolidované znenie)通道未开;效力状态(现行/有限期/废止)按原生日期字段全覆盖(读法见源文件 §4)。

## 2. 共享访问准备

- **无需 API key**(`.env` 空配置即可);无会话、无浏览器,HTTP 直连。
- **数据目录**:`{data_root}/SVK_policy/`(state.db + 01_raw/slovlex/ + failures/)。
- **限速节奏**:1–2 秒/请求实测无拦截;命令行统一 `--delay MIN:MAX` 可调。
- **出口注意**:源站应用层防火墙按出口网际协议地址选择性拒答(部分网络出口全量 404)——遇到时配置 `HTTPS_PROXY` 环境变量换出口,命令不变(2026-09-08 实测记录)。
- **编码**:正文页响应头不声明字符集,必须显式按 UTF-8 解码(源文件 §1.3 有踩坑实录)。
