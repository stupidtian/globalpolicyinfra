# 墨西哥（MEX）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）；九节写作结构见 [_template-zh.md](../_template-zh.md)。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `dof` | **联邦公报层**（Diario Oficial de la Federación，墨西哥联邦政府官方公报）：联邦法律、法令、部委协议、通告、公告等当日刊出序列。晨版（Matutina）为主刊，晚版（Vespertina）偶有补充 | dof.gob.mx 按日期+刊次寻址的版面页（HTML）+ 按条目号寻址的正文页（HTML），免 key、免注册 | [dof-zh.md](./dof-zh.md) |

## 1b. 三种数据结构现状

- **时间序列**：✅ 由 `dof` 承担——按刊出日（publication_date）逐日的完整颁布序列；公报层原生只有刊出日（签发日在正文中、无结构化字段，如实记缺）；类型、签发机关、语言（spa）、正文文件、可重建的 source_url 齐备。
- **决策过程**：未收——议会过程（Gaceta Parlamentaria，国会公报）不在本源范围，另立源时记缺。
- **版本序列**：未收——公报无原生版本谱系（刊出即定、不可变快照）；现行法整合库（如 ordenjuridico 类站点）未评估，需要时另立源。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `python cli.py init` 配置，或 `POLICY_DATA_ROOT` 环境变量；墨西哥数据落在 `{data_root}/MEX_policy/` |
| 密钥 | **无需任何 key**，`.env` 不需要条目 |
| 通用命令习惯 | `collect`（key=value 传参）/ `status` / `export` / `requeue` / `reset`，全部在仓库根目录 `python cli.py` 运行 |
| 网络 | dof.gob.mx 宿于联邦政府自有 Telmex 地址段（187.218.29.0/24），**对部分网络环境不可路由**（2026-09-14 实测：美/欧多点访问正常、延迟 0.5–2.7 秒，而个别网络的整段路由超时且该网 UDP DNS 应答被污染）。若所在网络到该段不通，标准解法是给进程设置 `HTTPS_PROXY` 环境变量走代理——传输层基于 requests，原生识别该变量，零代码改动 |
| 节奏 | 建议 `--delay 1:2`：站点无公开限额，礼貌起见逐日小窗口采集 |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 晚版（Vespertina）与特刊（Extraordinaria） | 采集器已按刊次参数化（`ediciones=MAT,VES`），晚版默认未开；特刊刊次代码未实测 |
| 逐条 PDF / 整期影像 | 正文页以 HTML 为主文件；`nota_to_pdf.php`（逐条 PDF）与 `nota_to_imagen_fs.php`（逐条 JPG，扫描年代）未接入 |
| 1994 年前扫描年代 | 公报电子化以 1994 年为界（此前为扫描影像）；当前正文通道不覆盖影像年代 |
| 州级公报 | 各州公报独立运营，不在联邦源内 |
| 国会文件 | Gaceta Parlamentaria（国会辩论与提案过程）另立源 |
