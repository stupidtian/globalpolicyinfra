# 巴西（BRA）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `dou` | 巴西联邦官方公报（Diário Oficial da União，简称 DOU）第 1 刊（Seção 1）及其特刊中的**规范类文件**：法律（Lei）、临时措施令（Medida Provisória）、宪法修正案、法令（Decreto）、部委令（Portaria 族）、决议（Resolução）、规范性指令、更正（Retificação）——约占该刊体量一半，其余程序性/司法性内容默认不收（参数可扩） | in.gov.br 门户：按日/刊的阅读页（内嵌 JSON 条目清单）+ 每条目一篇详情页 HTML（gzip 存储） | [dou-zh.md](./dou-zh.md) |

## 1b. 三结构现状

- **时间序列**：`dou` 源承担——按**刊日**组织的联邦规范公布序列，**2013–2025 已全量入账（399,561 文档）**，此后经 `sync=1` 增量续接（接口覆盖自 2013-01-02 起；2012 年及更早的年代该接口无数据，批量打包文件层回填另议）。**主用区间 2016–2025**：2013–2015 因源站回溯迁移不全而稀疏（详见 dou-zh.md §8，官方打包 XML 通道可补其中大部、2015-03..07 两通道同缺）。
- **决策过程**：记缺。国会的提案与审议数据有免钥开放接口（众议院 dadosabertos.camara.leg.br、参议院 legis.senado.leg.br/dadosabertos，2026-10-02 实测可用），属过程数据结构，未来作为第二源另批接入。
- **版本序列**：记缺。联邦规范的现行整并文本在总统府民法典站（planalto.gov.br/ccivil_03，静态整页）与其立法门户（www4.planalto.gov.br，对人机混合访问弹验证码挑战，2026-10-02 实测），无免挑战的枚举通道。

## 2. 共享访问准备

- **数据目录**：`{data_root}/BRA_policy/`（框架标准布局；`python cli.py` 在仓库根运行）。
- **API key**：**不需要**，`.env` 无需任何条目（2026-10-02 实测全部端点免钥）。
- **网络出口**：源站对部分网络环境有出口级拦截——实测（2026-10-02）中国大陆直连被连接层重置，经代理出口正常。采集运行时给进程设标准环境变量即可，零代码：
  `HTTPS_PROXY=http://<代理地址> HTTP_PROXY=http://<代理地址>`。
- **限速**：框架统一限速默认足够（连日实测数百请求零拦截、零验证码）。
- **响应格式**：枚举页 = HTML 内嵌一段 JSON；条目页 = HTML（UTF-8，gzip 压缩落盘）。正文载体 = 条目页 HTML（公报 PDF 版面件不随收，取数参数已入账，见 dou-zh.md §8）。**纯文本层**：`dou_clean` 已声明（`python cli.py clean --country bra`），01_raw 去门户装饰后落 `02_cleaned/`（正文+签署人，UTF-8 行界文本）。

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 公报 Seção 2（人事任免）与 Seção 3（司法、公告） | 不在默认范围；`secoes` 参数可扩（见 dou-zh.md §3） |
| 国会立法过程（提案、审议、投票） | 记缺，接口在案，未来第二源 |
| 现行整并文本（法规当前有效版） | 记缺（Planalto 门户有反爬挑战） |
| 2012 年及以前的公报 | 无条目级数据；旧版公报系统有整页 PDF（约 1990–2012 间可达、免 key、有文字层，零星空洞），该形态的回填源另议 |
| 州/市级公报（各州自出公报） | 不做（联邦层级限定） |
| 判例 | 不做 |
