# 土耳其（TUR）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）。

## 1. 源清单

土耳其是一对**总统府（T.C. Cumhurbaşkanlığı）双系统**：一个管公布、一个管现行态。

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `resmigazete` | **Resmî Gazete**（土耳其官方公报）：一切国家层规范的法定公布媒介——法律、总统令、规章、通告等在此公布才对第三人有效。**公布流**（何时公布了什么原文），2000-06-28 起逐日完整 | 公报站逐日索引页（fihrist）+ 单文文件（HTML/PDF）直连，免 key 免注册 | [resmigazete-zh.md](./resmigazete-zh.md) |
| `mevzuat` | **Mevzuat Bilgi Sistemi**（法规信息系统，MBS）：公报公布的法规的**整编现行文本**（历次修正并入原文的合并版）+ 废止法规库。**现行态**（现在有效的是什么），全库约 19,095 部实体（2026-09-27 计数） | 法规信息系统站内数据接口（JSON 名录 + 整编正文网页），免 key 免注册 | [mevzuat-zh.md](./mevzuat-zh.md) |

两站互链、同属总统府总秘书处法务与立法总局体系运营；两源数据可交叉对账（同一部法律在两边的公报日期/期号一致，2026-09-27 以 7595 号法律实测核对）。

## 1b. 三结构现状

- **时间序列**：`resmigazete` 源承担，2000-06-28 起逐日完整（更早年代为整期扫描件通道，见该源文档 §8）；公报日、条目文件头部的通过日分开收；生效日源站无独立字段（写在条文里），记缺。
- **决策过程**：无（议会 TBMM 审议过程数据不在本两源；需要时另立源）。
- **版本序列**：`mevzuat` 无原生版本时间线（整编库只存现行合并文本 + 废止标记）；as-published 的版本链由 `resmigazete` 的公布原件天然构成；`mevzuat` 的废止库（mülga）提供"法规退役"发现层。

## 2. 共享访问准备

- **数据目录**：`{data_root}/TUR_policy/`（两源共用一国一库，state.db 内按源分任务类型）。
- **密钥**：两源均**不需要**任何 API key，`.env` 无需条目。
- **命令习惯**：与所有国家一致——`python cli.py collect --country tur --source {源名} …`；状态查询 `python cli.py status --country tur`。
- **限速节奏**：两站均为政府站点、无反爬无验证码（2026-09-27 直连实测，curl 裸请求即可）；框架默认 0.5–1 秒/请求。土耳其语单语（拉丁字母），HTML 正文注意 **Windows-1254** 编码（见 resmigazete 文档 §2）。
- **robots**：两站 robots.txt 只含针对搜索引擎的 Noindex 提示、无 Disallow 与 Crawl-delay（2026-09-27 实测）。
