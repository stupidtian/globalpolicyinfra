# 英国（GBR）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件（本目录下 `{源名}-zh.md`）。
> 建议先读仓库根目录 README 了解 `python cli.py` 的用法。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `leg` | 联合王国层级法律（ukpga）与法定文书（uksi）的**颁布原样版全文**（CLML XML），制定/提交/施行日期三件套 | legislation.gov.uk 官网 API 通道（内容协商取 XML） | [leg-zh.md](./leg-zh.md) |
| `lex`（规划中） | 全库 22 万件元数据、193 万条现行条文正文、257 万条修订关系台账、9.2 万条解释说明（parquet 整包） | 英国政府 i.AI 部门的 Lex 服务（对同一语料的再发布，免密直下） | 待该源实施时补写 |

两源汇合于同一张 `items` 实体表（一件法规一行）：leg 源写入颁布层信息，lex 源只补不改地填入现行版列。

## 1b. 三结构现状

- **时间序列**（强制底线）：leg 源主体——按制定日逐年组织，序列完整（清单轴发现全部条目，日期三件套齐备）；缺口仅"无 XML 的 PDF-only 件"的正文（题名编号仍在账）。
- **决策过程**：暂无源（议会立法过程在 bills.parliament.uk，未开）——记缺。
- **版本序列**：颁布原样版（leg 源）已收；现行有效版与修订台账随 lex 源；逐时点历史版本通道已验证（leg-zh.md §9），另批实施。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 密钥 | 两源均**免 key**，`.env` 无需条目 |
| 限速 | legislation.gov.uk：robots.txt 要求 5 秒/请求，另限 3,000 请求/5 分钟——运行加 `--delay 5:7`；lex 整包下载无限制 |
| 身份 | 站方公平使用政策要求自动化访问自报 User-Agent（国家包内已固定带联系方式） |
| 语言 | 语料为英文（eng） |
| 数据目录 | `{data_root}/GBR_policy/`（state.db + 01_raw/） |
| 许可 | Open Government Licence v3.0（注明来源即可再利用） |

## 3. 尚未覆盖的政策层
