# 沙特阿拉伯（SAU）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| uqn | 官方公报乌姆古拉（أم القرى）的官方部分（法律法规、皇家敕令/命令、部长会议与部门决定）+ 期册 PDF；条目级自 2026-01 起 | uqn.gov.sa（公报官网，新闻部出版） | [uqn-zh.md](./uqn-zh.md) |

## 1b. 三结构现状

- **时间序列**：uqn 源承担——每条公报条目一行（刊出日为公历 `publication_date`，原生伊斯兰历签署日存 `meta.native_date_hijri`，两历并收不换算）；2026 年前的老年代只有期册 PDF（约 750 期），条目级序列缺口记入源文档第 8 节。
- **决策过程**：记缺——沙特无民选议会，协商会议（مجلس الشورى）无公开过程数据源可采。
- **版本序列**：记缺——公报型源无原生版本谱系；现行法规的编纂版本在部长会议专家局法规库（laws.boe.gov.sa），因网络可达性受限未接入，另行立项。

## 2. 共享访问准备

- 数据目录：默认 `POLICY_DATA_ROOT` 下的 `SAU_policy/`（`python cli.py` 首次运行自动建骨架）。
- 密钥：**无需任何 key**（`.env` 无 SAU 条目）。
- 命令习惯：`python cli.py collect --country sau --source uqn window=YYYY-MM:YYYY-MM`（月份窗）；增量 `sync=1`。
- 限速节奏：站点响应较大（条目页约 0.8 MB/次），保持默认 `--delay` 即可；该源无会话、无状态，声明可并发（并发仍受全局速率闸门约束）。

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 官方公告（إعلانات） | 已接通、默认不收（`sections=decisions,advertisements` 放开） |
| 2012–2025 期册 PDF（约 3 GB） | 已勘明编址，回填另立项 |
| 1924–2011 历史公报 | 不在 uqn 站内（国家档案与记录中心管辖），出界 |
| 现行法规库 BoE（laws.boe.gov.sa） | 全球可达性正常、部分网络环境不可达；版本序列候选源，另立项 |
| 协商会议过程数据 | 无公开过程源，记缺 |
| 宗教裁决（فتوى）、地方/市政公告、判例 | 出界 |
