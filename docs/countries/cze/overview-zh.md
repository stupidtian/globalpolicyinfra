## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| esbirka | 《法规汇编》(Sbírka zákonů)1993 年起的全部公布条目:宪法性法律、法律、政府条例、部委规章(vyhláška)、宪法法院判决、通知通告类 | e-Sbírka 门户(内政部运营的官方电子汇编系统)的开放接口,免 key、无会话、无浏览器;逐件正文为 XML(信息化包提取,不抓 PDF,全年代可用) | [esbirka-zh.md](./esbirka-zh.md) |

## 1b. 三结构现状

- **时间序列**(必答):esbirka 源满足强制底线——一条公布事件一行,公布时间戳(电子时代精确到毫秒)、批准日、生效起/止、登记册状态全部为原生字段分开收录;1993–2026 年序列连续完整(登记册实测 16,124 条,2026-10-15)。正文:逐件 XML,全年代(1918 年起)同通道。
- **决策过程**:无——议会过程(众议院立法流程)尚未开源,记缺;需要时另立过程源。
- **版本序列**:原生存在但本源不收——汇编的时点整合版本(časové znění)与版本谱系是门户原生数据(版本列表、编纂链接数据集),留给未来按需扩展;本源只收公布原文(事件层)。

## 2. 共享访问准备

- **数据目录**:`{data_root}/CZE_policy/`(账本 state.db 与 01_raw 同根)。
- **密钥**:无需任何 API key(`.env` 不需要条目)。
- **命令习惯**:一切经 `python cli.py collect --country cze --source esbirka …`;限速用默认即可,大批量回填建议 `--delay 3:6` 分批(2026-10-15 实测:约 50 次快速连发触发一次传输层截断,间隔后自愈)。
- **年代边界**:1918–1992(捷克斯洛伐克时代)在本源出界,命令行显式拦截;1993 年起可抓。
