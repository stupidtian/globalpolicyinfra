# 挪威（NOR）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）；九节写作结构见 [_template-zh.md](../_template-zh.md)。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `lovtidende` | 挪威法规公报（Norsk lovtidende）Del I：法律（lov）与中央法规（sentral forskrift）——挪威全国性规范的全部官方公布条目（2001 年起电子官方公布全序列，每年约 1,200–2,300 条） | api.lovdata.no 官方开放数据整包（免 key、无会话、NLOD 2.0 许可；冻结档案包 + 当年日更包，一条一 XHTML） | [lovtidende-zh.md](./lovtidende-zh.md) |

## 1b. 三种数据结构现状

- **时间序列**：✅ 由 `lovtidende` 源承担——2001 年起逐年完整序列全量入账（39,143 条，2026-09-03；与官方网页登记册逐年对账精确一致），每条带制定日 / 公布日 / 施行日三个日期（施行日约 19% 为"由国王谕定"类自由文本，原样收）。
- **决策过程**：未收——议会（Storting）过程系统未开，记缺；法律条目自带的议会过程说明串（提案号/委员会报告/两轮审议日期）已随公报元数据无损收进 meta。
- **版本序列**：未收——公报无原生版本谱系；现行法律/现行中央法规两份整包（gjeldende-*）的官方机器通道已确认存在（2026-09-03 实测清单在列），需要时另立源，清单见 [lovtidende-zh.md](./lovtidende-zh.md) §9。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `python cli.py init` 配置，或 `POLICY_DATA_ROOT` 环境变量；挪威数据落在 `{data_root}/NOR_policy/` |
| 密钥 | **无需任何 key**，`.env` 不需要条目 |
| 通用命令习惯 | `collect`（key=value 传参）/ `status` / `export` / `requeue` / `reset`，全部在仓库根目录 `python cli.py` 运行 |
| 节奏 | 框架统一限速 + 错误三分法重试；本源每次运行 1–3 个请求（清单 1 + 每包 1），官方限额 200 请求/分钟远未触顶 |
| 许可 | NLOD 2.0（挪威开放政府数据许可）：允许商用与非商用再利用，**须署名**（Kilde: Stiftelsen Lovdata）——引用规范见 [lovtidende-zh.md](./lovtidende-zh.md) §2 |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 议会立法过程（法案、审议、表决） | Storting 议会系统，未开工（公报 meta 中的议会过程串是原始素材，见 1b） |
| 地方性法规（公报 Del II） | 县级/市级法规另一公布体系，无官方整包数据，未开工 |
| 现行有效版本（法规汇编） | 官方整包通道已确认（见 1b），未开工 |
| 1982–2000 年公报条目 | 网页登记册有目录但全站禁抓、无官方整包——记缺，处置建议见任务报告 |
| EU 法原文 | 经 EEA 协定并入的 EU 法案原文刊登在单独的 EØS-tillegget（EEA 公报附录），无整包数据、未开工；转化产物（实施 EEA 指令的挪威法律/法规）已在公报源内（标题含 EØS 的 616 条、原生引用字段 90 条） |
| 判例（法院判决） | 不在公报 Del I 范围（Lovdata 另有判例库，付费），不做 |
