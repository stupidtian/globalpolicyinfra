# 日本（JPN）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `kanpo` | **官報**（日本国家官方公报）：法律、政令、府省令、规则、训令等法令类文件的**颁布事件序列**与颁布时**原样 PDF**，2026 年起可增量，在线档案回溯到 2003-07-15 | 官報発行サイト（kanpo.go.jp）：静态 HTML 目录页（日期编址）+ 条目 PDF 直链，免 key | [kanpo-zh.md](./kanpo-zh.md) |

## 1b. 三结构现状

- **时间序列**：`kanpo` 源主体——官報按发行日全序列，默认口径（法令等节）自 2003-07-15 起全时段一致；刊出日入账齐全，制定日/施行日在 PDF 正文中、留待清洗阶段抽取。
- **决策过程**：无源。国会两院（衆議院/参議院）的法案提出、审议、表决不在官報（官報只登颁布结果）；国立国会图书馆的国会会议录（1947 年起全文）是候选通道，未建源。
- **版本序列**：无源。官報是颁布原样公报、无版本谱系；现行法令的汇编文本在 e-Gov 法令検索有免 key 机器通道（标准 XML 全文 + 每日更新流，2026-09-07 实测验明），需要时另立源。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `{data_root}/JPN_policy/`（state.db、failures/、01_raw/kanpo/…） |
| API key | 日本各源均不需要（`.env` 无条目） |
| 传输 | 全部普通 HTTP GET，无会话无 cookie 无反爬；框架默认限速即可，官報源建议 `--delay 1:2` |
| 身份 | 传输层自报 User-Agent（学术研究爬虫 + 开源仓库地址），不伪装浏览器 |
| 语言 | 日语（`jpn`）；页面 UTF-8；官報 PDF 为 cid 字体纵向排版（文本抽取注意，见 kanpo-zh.md §2） |
| 许可 | 官報内容适用公共データ利用規約 PDL1.0（署名即可再利用） |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 国会立法过程（法案审议、表决记录） | 未建源（国会两院系统 + 国会会议录，见 §1b） |
| 现行法令汇编文本（e-Gov 法令検索） | 通道已验明，未建源（见 §1b） |
| 1953-01-01 ～ 2003-07-14 的官報 | 互联网无公开档案，无法批量获取（付费检索服务与到馆是仅有渠道） |
| 1883-07-02 ～ 1952-04-30 的官報（国立国会图书馆扫描件） | 互联网公开、IIIF 可取，未建源（图像源、独立工程） |
| 地方自治体公报（都道府県公報） | 不在本项目国家层范围 |
