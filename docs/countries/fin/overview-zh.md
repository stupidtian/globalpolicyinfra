# 芬兰（FIN）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）；九节写作结构见 [_template-zh.md](../_template-zh.md)。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `finlex` | **法规公报层**（säädöskokoelma）：芬兰国家层级全部规范的原样公布序列——议会法律、政府令、部委令（后两类同码）、当局决定、国家预算与补充预算、通告等。2025 年实测 1,508 部（新订 333 / 修订案 1,126 / 废止案 49），双语（芬兰语/瑞典语）覆盖 100%；数字档案自 **1917 年**（独立）起连续，更早为散件（1734 年法典等） | opendata.finlex.fi 官方开放数据 REST API（免 key、Akoma Ntoso XML、服务端按日/按年过滤、每表现一请求） | [finlex-zh.md](./finlex-zh.md) |

## 1b. 三种数据结构现状

- **时间序列**：✅ 由 `finlex` 公报层承担——**2000–2026 年已全量回填**（2026-09-15 完成，芬兰语 37,550 件，逐年对账 99.93%），更早年份可随时按 `year=` 入口扩展。日期口径：制定日全量覆盖；刊出日约 2019 年起有结构化值（2000–2018 年代源站原生缺失，见 [finlex-zh.md](./finlex-zh.md) §8）；生效日公报层无结构化字段（在正文条款中，如实记缺——现行法整合层有结构化生效日，通道已确认，另行扩展）。
- **决策过程**：未收——政府提案（HE）文档族在接口的 `doc/*` 路径族下（2026-09-13 实测确认存在），需要时另立源，记缺。
- **版本序列**：未收——现行法整合层（statute-consolidated，ajantasainen lainsäädäntö）原生维护"一部法一实体、多时点版本谱系 + 效力状态 + 废止链"，机器通道 2026-09-13 实测确认可用，需要时另立源（见 [finlex-zh.md](./finlex-zh.md) §9）。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `python cli.py init` 配置，或 `POLICY_DATA_ROOT` 环境变量；芬兰数据落在 `{data_root}/FIN_policy/` |
| 密钥 | **无需任何 key**，`.env` 不需要条目 |
| 通用命令习惯 | `collect`（key=value 传参）/ `status` / `export` / `requeue` / `reset`，全部在仓库根目录 `python cli.py` 运行 |
| 节奏 | 建议 `--delay 0.5:1.5`：源站对无连接复用的快连会直接掐断（无 429），框架传输层会话复用 + 重试可穿过偶发断连（2026-09-13 实测：0.6 秒间隔连发 302 页零掉线） |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 现行法整合层（ajantasainen，版本谱系 + 效力状态 + 废止链） | 机器通道已实测确认（见 1b），未开工 |
| 机构规章与指引（viranomaisen määräys/ohje，如交通局、金融监管局自发规章） | 独立接口族（`doc/authority-regulation`，按签发机构编址）已实测确认，未开工——类比"机构指引层" |
| 政府提案（HE，议会决策过程） | `doc/*` 接口族已实测确认，未开工 |
| 判例（最高法院、最高行政法院等） | `judgment/*` 接口族存在，未开工 |
| 萨米语与外语翻译版本 | 网站为翻译版本单列站点地图（statute-sami-translation 等），接口内未见对应表现，未评估 |
| 市镇/地方层 | 各市镇规范不在国家公报内，未开工 |
| EU 法原文 | 欧盟条例直接生效、不经芬兰公报刊发；需要时另立 EU 源 |
