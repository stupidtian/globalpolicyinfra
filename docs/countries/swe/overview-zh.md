## 1b. 三结构现状

- **时间序列**(必答):基础法层达标——每部新颁布的基础法一行(颁布日 Utfärdad 为时间轴主日期);颁布日 / 生效日(正文首部标记)/ 平台登记日(运维侧)分开收。**修订法(编号空间的 91%)不在其中**:机器通道不将其作为独立文档,其效力以标记内嵌母法文本、随抓无损;修订法元数据清单(年 1,600+ 条)在政府新测试系统的数据层,将来另立修订事件源即有挂点。
- **决策过程**:记缺——议会立法过程(提案 proposition / 委员会报告 betänkande / 表决记录 riksdagsskrivelse)在议会 API 的其他文档类型下,未采。
- **版本序列**:记缺(部分)——正文为现行合并版(抓取时刻快照),头块带"修订截至 SFS 年:号"戳可判别文本口径(未被修订的 34.1% 恒为颁布原文);历史时点文本与修订法清单无机器通道(2018 年前印刷 PDF 档案除外)。

## 2. 共享访问准备

- **无需 API key**(`.env` 空配置即可);无会话、无浏览器,HTTP 直连。
- **数据目录**:`{data_root}/SWE_policy/`(state.db + 01_raw/riksdagen/ + failures/)。
- **限速节奏**:源站在连续快速访问数十次后出现间歇性 TCP 连接重置(冷却数分钟自愈,2026-09-09 实测)——命令行统一 `--delay 2:5`,传输层自动重试可消化;大回填放慢分批。
- **编码**:列表 XML 与正文 HTML 均为 UTF-8 且无编码声明,解析显式按 UTF-8 解码(瑞典语 å ä ö 全链路实测无损)。

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
