# 瑞典(SWE)数据源说明——riksdagen(议会开放数据 API:SFS 瑞典法规公报)

> 数据快照日期:2026-09-09。文中条目计数、字节数与字段值均为当日对源站直连实测的真实值(样本已存档,可重放复核);账本内计数在首次真实运行后补记(§5 末行)。
> 阅读前提:了解 `python cli.py` 用法即可,不需要读代码。瑞典全部源总览见 [overview-zh.md](./overview-zh.md)。

## 1. 源概览

### 1.1 制度背景:SFS 是什么、装了谁的产出

**SFS**(*Svensk författningssamling*,瑞典法规公报)是瑞典**国家层级规范文件的官方颁布序列**:法律与政府条例按 **年:序号** 编号颁布(如 `2026:1776`),一个编号 = 一次颁布 = 一份文件。每年从 1 号起连续编号,2026 年到 9 月 9 日已编至 1778 号(实测)。

**谁颁布、谁维护**:法律(*lag*)由议会(Riksdagen)通过;政府条例(*förordning*)由政府(Regeringen)在法律授权下颁布——后者是政府层规制的主力,也是本语料的**主体**(类型构成 2026-09-09 全页抽样:1990 年样本政府条例 41/50、法律 7/50;2024 年 42/6)。序列的维护方是政府办公部门(Regeringskansliet)的法律数据库;**议会在自己的开放数据平台转载全套数据**(每份文本头部自注来源 `Källa: Regeringskansliet / Lagrummet`),本源即走议会转载通道 `data.riksdagen.se`——语料与政府登记册同源,官方性等同,接口更开放(见 §1.3)。

**编号空间的构成**(2026 年 1..1778 全量核算,2026-09-09 实测):

| 层 | 数量 | 占比 | 说明 |
|---|---|---|---|
| **基础法**(grundförfattning) | 151 | 8.5% | 新颁布的独立法规(新法律、新政府条例等),登记册的一级条目,**本源采的就是这一层** |
| **修订法**(ändringsförordning / ändringslag) | 1,626 | 91.2% | 对既有法规作局部修改的独立编号文件("Lag (2026:1243) om ändring i skollagen (2010:800)" 这样只改母法某几条的文件);**机器通道不将其作为独立文档提供**(见 §1.2) |
| 残留 | 5 | 0.3% | 公告类(*kungörelse*,人事任免等),确非政策 |

三层的并集覆盖 2026 年 1..1778 号中的 1,773 个编号(4 个编号兼具基础法与修订法双重身份);残留 5 个为公告类。核算方法:政府登记册每部基础法名下的修订法清单全量汇总(1,626 个编号,零重复)与议会列表枚举求并集,2026-09-09 实测。

### 1.2 两个关键口径:语料 = 基础法层;正文 = 现行合并版

**口径一:机器通道只承载基础法。** 编号空间 91% 的修订法,在议会接口上无独立文档(2026-09-09 实测:修订法编号直取返回 404,全文检索该编号只命中其母法);政府新测试系统的数据层里有修订法的**元数据清单**(编号/标题/生效日/议会案号/修订目标),但无全文,且该接口只接受 POST 请求体查询,本源不依赖(§8)。修订的**效力**则完整可见——它以标记形式折入母法文本:改动处标注修订法编号(如 `Lag (2026:1243)`),设失效期的条款标注 `/Upphör att gälla U:2027-07-01/`。修订关系建图因此留给分析阶段,原始标记随文本无损落盘。

**口径二:正文是"抓取时刻的现行合并版"(*sammanhängande text*)。** 瑞典的官方机器文本按现行有效状态维护,历次修订成果已合并进条款(实测:Skollagen 2010:800,2010 年颁布,今日抓取为 71.7 万字符、29+ 章、内嵌 134 部修订法标记的合并文本)。由此:

- **未被修订的法**(全库 34.1%,2026-09-09 实测 9,119/13,846 部被修订过、34.1% 从未):任何时刻抓到的都是颁布原文(实证:Förordning 1990:493,1990-06-07 颁布,头块修订字段为空,文本即 1990 年原样);
- **被修订过的法**(65.9%):抓到的是合并到抓取当日的版本,颁布年原貌不可得——头块的 `Ändrad` 字段可精确区分两种状态(空 = 原文;非空 = 合并版,且带"修订截至 SFS 年:号"戳);
- **当年增量抓当年新法**:新法尚未被修订,合并版 = 颁布版,文本保真;颁布原文的不可得只影响**往回**补采被修订的老法。

### 1.3 数据通道:议会开放数据 API(免 key、无会话、无浏览器)

**① 列表接口**(枚举的唯一入口):

```
GET https://data.riksdagen.se/dokumentlista/?doktyp=sfs&rm={年}&sz=100&p={页}
```

- XML 封套 `dokumentlista → dokument[]`,封套属性 `traffar`(命中总数)/ `sidor`(总页数)/ `nasta_sida`(下一页地址);
- 条目字段(2026-09-09 实测全集):`dok_id`(文档标识,如 `sfs-2026-1776`)、`beteckning`(SFS 编号 `2026:1776`)、`nummer`(序号)、`datum`(**颁布日 Utfärdad**)、`organ`(发布机关)、`titel`(标题)、`rm`(编号年)、`publicerad`(平台登记时间戳);
- **参数实测陷阱**:`from`/`to` 日期窗口对 sfs 类型**失效**——传入 2026-06-01..07 的窗口返回的 71 条中 27 条颁布日在窗口外(2026-09-09 多窗口对照,含 2020/1990 窗口交叉验证);`sort` 参数同样被忽略。**分区只信 `rm`(编号年)**,本源只用它;
- 旧域名 `api.riksdagen.se` 已停止解析,现址为 `data.riksdagen.se`(接口版本 3.8.5,2026-09-09 实测)。

**② 正文接口**(按编号直取):

```
GET https://data.riksdagen.se/dokument/{dok_id}.html
```

- 响应为结构化 HTML 片段:`<h2>` 标题 → 元数据头块 → (长法)目录 → 带段落锚点(`<a name="S1">`、`<b>2 §</b>`)的正文;
- **头块字段**(全部实测):`SFS nr`(编号)、`Departement/myndighet`(发布机关)、`Utfärdad`(颁布日)、`Ändrad: t.o.m. SFS {年:号}`(修订截至,**未修订无法此行**)、`Ändringsregister`(政府修订登记链接)、`Källa`(政府全文来源链接);
- **生效日**以斜体标记内嵌正文首部:`/Träder i kraft I:{日期}/`(如 2026:1776 为 `/Träder i kraft I:2027-01-01/`)——接口无结构化生效日字段,解析此标记,缺席(如通告类)如实留空;
- **越界行为**:不存在的年/号返回干净 404(`sfs-2026-99999`、`sfs-9999-1` 实测)。但**编号空间有洞**(登记册只收基础法与通告,2026:500 缺席而 2026:578 在)——**逐号盲枚举不可行**,发现必须走列表接口;
- 同一地址换 `.text` 后缀得纯文本版(头块多一行 `Omtryck` 重印标记,正文无锚点);本源主用 `.html`(结构化),`.text` 备用;
- 人读正门为 `https://www.riksdagen.se/sv/dokument-och-lagar/dokument/{标题slug}_sfs-{年}-{号}/`(slug 必需,采集不走此形式)。

**覆盖与登记节奏**(2026-09-09 实测):全库 **11,564** 条,**时间跨度自 1736 年**(该年 2 条,与政府登记册一致;1800 年 0 条);年度规模 112–206 条/年(2021–2026 依次 174/206/112/161/152/153;1950/1970/1980 为 21/98/116,2005/2010/2015 为 159/191/150)。列表的 `publicerad` 时间戳集中于每日 04:30–04:40 批次;**颁布日 → 平台登记日滞后数日**(2026:1776 颁布 09-03、登记 09-08/09)——增量设计据此做滞后容错(§7)。

## 3. 抓什么:任务类型清单

每种任务 = 一次下载 + 一次解析。共 **2 种**:

| 任务类型 | 请求什么 | 产出什么 |
|---|---|---|
| `sfs_list`(种子,每年每页一个) | GET 列表接口(§1.3 ①)`rm={年}&sz=100&p={页}` | 当页每个条目生成一个 `sfs_doc`;`p < sidor` 则生成下一页 `sfs_list`;该年 0 条(编号序列未覆盖的久远年份)→ 合法空产出 |
| `sfs_doc` | GET 正文接口(§1.3 ②)`/dokument/{dok_id}.html` | 一个文档记录 + 响应字节原样落盘为 `doc.html` 主文件;解析头块五字段 + 正文首部生效日标记;**列表条目与页面头块交叉校验**(编号或颁布日不符 → 按形状突变告警升级,绝不静默) |

任务链:`sfs_list × 每年每页 → sfs_doc × 每条`。

命令行参数(key=value 形式):

```
years=2026         单年采集;years=2024:2026 为闭区间多年(必填,或改用 sync=1)
sync=1             增量:重走上一年 + 当年的列表页(为什么是两年见 §7)
```

## 4. 数据落到哪

**零领域表**(扁平文档型路径,同西班牙 BOE / 斯洛伐克 slovlex):本语料一个 SFS 编号对应一份文档,没有跨文档的持久实体;修订法不是文档(§1.2),其效力标记与母法同文件。一切研究字段进 `documents` 一张表:

| 列 | 内容 |
|---|---|
| `doc_id` | `SWE_{颁布日YYYYMMDD}_{hash8(source_url)}` |
| `title` | 头块标题(如 `Förordning (2026:1776) om ärendehanteringssystem och andra handläggningsstöd hos lantmäterimyndigheter`) |
| `publication_date` | 头块 **Utfärdad(颁布日)**——研究时间轴的主日期 |
| `issuing_authority` | 头块 Departement/myndighet(如 `Landsbygds- och infrastrukturdepartementet SPN`) |
| `source_url` | `https://data.riksdagen.se/dokument/sfs-{年}-{号}.html`——编号直接构造的规范形式,全年代稳定、无会话参数 |
| `raw_format` / `language` | `html` / `swe`(瑞典语) |
| `doc_type` | 由标题原生词映射的受控类型(下表);瑞典语原词永存 meta |
| `entity_ref` | NULL(零领域表) |

**meta 字段**(原生字段无损收,全字符串):`sfs_nr`(如 `2026:1776`)、`ar`(编号年)、`lopnummer`(序号)、`riksdagen_dok_id`(如 `sfs-2026-1776`)、`organ`(列表侧机关,与头块互证留档)、`andrad_tom`(修订截至戳,如 `SFS 2026:1636`,未修订为空——**文本口径的判别字段**:空 = 颁布原文)、`andringsregister_url`(政府修订登记链接)、`kalla_url`(政府全文来源链接)、`ikrafttradande`(生效日,正文首部标记解析;缺席如实留空)、`notis`(通告类标记,文档标识 N 前缀判定)、`files`(文件清单)。

**doc_type 映射**(原生优先:标题首词与全词永存 title/meta,映射只认原生形态,未见过的词一律 OTHER、零猜测):

| 标题原生词 | 文书 | doc_type |
|---|---|---|
| Lag / 复合词尾 -lag(如 Elmarknadslag) | 法律(议会) | STATUTE |
| Förordning / 复合词尾 -förordning(如 Vapenförordning) | 政府条例(政府规制) | REGULATION |
| Tillkännagivande(公告)、Kungörelse、其余 | — | OTHER |

**文件布局**(源名顶层、一法一夹、年分片防巨目录;SFS 编号中的冒号在路径里换为连字符):

```
{data_root}/SWE_policy/
├── state.db
├── failures/
└── 01_raw/riksdagen/
    └── 2026/
        └── 2026-1776/
            └── doc.html        ← 正文响应字节原样(标题+头块+目录+带锚点全文)
        └── N2020-13/
            └── doc.html        ← 通告类:仅头块、无正文(§5 案例 4),原样落盘
```

## 5. 完整案例走查(2026-09-09 源站直连实值,每步可重放)

1. **基础法(当年新颁)**:`sfs_list rm=2026` 首页给出 `dok_id=sfs-2026-1776`、编号 `2026:1776`、颁布日 `2026-09-03`、机关 `Landsbygds- och infrastrukturdepartementet SPN`;直取 `.html` 得 4,403 字节:头块 `Utfärdad: 2026-09-03`、无 `Ändrad` 行(未被修订 = 颁布原文),正文首部 `/Träder i kraft I:2027-01-01/`(2027-01-01 生效),9 条带锚点条款。落盘 `01_raw/riksdagen/2026/2026-1776/doc.html`,documents 一行(publication_date=2026-09-03,doc_type=REGULATION)。
2. **被深度修订的老法**:Skollagen `2010:800`,2010-06-23 颁布。今日直取 `.html` 为 1,005,279 字节,头块 `Ändrad: t.o.m. SFS 2026:1636`(修订截至 2026:1636,即合并版;meta.andrad_tom 同值),29+ 章带目录,正文内嵌 134 部修订法的标记(如条款尾注 `Lag (2026:1243)`)——一部法的现行全貌 + 修订痕迹一份文件全收。
3. **从未修订的老法**:Förordning `1990:493`,1990-06-07 颁布,今日抓取头块修订字段为空——文本即 1990 年颁布原样(§1.2 口径的正面实证)。
4. **通告类(notis)**:`N2020:13`(关于 SKOLFS 序列一处修订的公报通告),直取仅 844 字节:同一套头块、**无正文**(元数据即文档本体),原样落盘;颁布日 2021-10-22 与编号年 2020 差一年——通告类的编号年与颁布日偶发错位,分区按编号年、颁布日照实收,如实入账。
5. **越界与空洞**:直取 `sfs-2026-99999` → 404(干净);`2026:500` 不在语料(登记册未收)而 `2026:578` 在——编号空间有洞,枚举只走列表(§1.3)。
6. **账本内计数**:首次真实运行(试跑窗口 years=2026)后补记于此。

## 6. 怎么跑

```bash
# 演练(不入队执行,看会抓什么)
python cli.py collect --country swe --source riksdagen years=2026 --dry-run

# 单年真实采集(§5 案例 1 的当年窗口;~2 列表请求 + ~150 文档请求)
python cli.py collect --country swe --source riksdagen years=2026 --delay 2:5

# 多年区间(闭区间,如回补近三年)
python cli.py collect --country swe --source riksdagen years=2023:2026 --delay 2:5

# 增量(重走当年与上一年列表;已收文档自动跳过,见 §7)
python cli.py collect --country swe --source riksdagen sync=1 --delay 2:5

# 状态 / 快照 / 修复
python cli.py status --country swe
python cli.py export --country swe
python cli.py requeue --country swe
```

## 7. 更新与增量

- **无日期游标**(列表接口日期窗口参数失效,§1.3;编号年分区)。增量 = **参数化重开**:每次 `sync=1` 以新的时间戳参数重新走**当年 + 上一年**的列表页(约 2–6 个请求)——新颁布的基础法自动补抓;已收文档按确定性身份跳过,成本仅列表页。
- **为什么两年**:颁布日到平台登记日滞后数日(§1.3),跨年边界的条目(编号年 = 上一年、登记在当年)由上一年分区的重走覆盖。
- **文档抓一次定格(快照口径)**:已收文档不因平台登记时间戳变化而重开——正文是随修订漂移的现行版,重复抓取会造成同一文档的文件与账本校验和不一致;修订追踪的需求由文本内标记(分析侧建图)与将来的修订事件源(§8)承担。
- 同窗口重复运行零请求(任务确定性去重);更老年份的重采不影响已收数据(编号身份不变,直接跳过)。

## 8. 已知边界与缺口

| 缺口 | 说明 |
|---|---|
| **修订法层(编号空间 91%)** | 无独立文档;效力以标记内嵌母法文本(无损)。修订法的元数据清单(年 1,600+ 条:编号/标题/生效日/议会案号/修订目标)存在于政府新测试系统(beta.rkrattsbaser.gov.se)的数据层,但其接口只接受 POST 请求体查询,且为测试版本——将来可另立修订事件源,本源不依赖 |
| **被修订老法的颁布年原文** | 机器文本只给现行合并版;未修订的 34.1% 恒为原文(§1.2)。需要历史时点文本的研究请以 `andrad_tom` 字段甄别 |
| 公告类残留 | 2026 年仅 5 个编号(kungörelse 人事任免类),不在语料 |
| 机关规章全文 | 各机构自己的公报序列(NFS / SKOLFS / SJVFS 等约 40 个),SFS 只收指向它们的 N 号通告;要收全文需按机构另立源 |
| 政府委员会指令 | Kommittédirektiv 在政府办公部门另一数据库,不在 SFS |
| 欧盟法 | 直接适用的欧盟条例不在 SFS |
| Omtryck(重印) | `.html` 头块未携带此标记(`.text` 版有);重印稀有,如实记缺 |
| 生效日非结构化 | 靠正文首部 `/Träder i kraft I:{日期}/` 标记解析,通告类与个别形态缺席时留空 |
| 跨年错位 | 通告类编号年与颁布日偶发差一年(§5 案例 4);照实入账,不强行对齐 |
