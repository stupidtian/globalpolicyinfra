# 斯洛文尼亚（SVN）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| uradnilist | 官方公报《Uradni list RS》1991-01-18 起的法规公布时间序列。**双载体**：2026-03 前每法规一个存档 HTML 正文页（主文件，`clean` 一键提纯文本）+ 整期 PDF 原件存档；2026-03 起一法一 PDF（主文件） | 两个免 key 免会话源：PISRS（pisrs.si，日历/按日清单/PDF 原件）+ 旧公报官网存档（uradni-list.si，每法规 HTML 正文页，靠公报条目号连接） | [uradnilist-zh.md](./uradnilist-zh.md) |

斯洛文尼亚语（`slv`）为拉丁字母文字（含 č/š/ž 变音符），解析与文本处理无特殊层。斯洛文尼亚为欧盟成员，EU 指令经普通国内立法程序转化，在本源内正常逐条采集。

## 1b. 三结构现状

- **时间序列**：本任务主体，已建成——uradnilist 源按公布日一条法规一行，1991-01-18（独立后首期）至今全时段可采；日期字段收公布日（清单行的原生日期；法规的采纳日/生效日清单不携带，见源文档 §8）。
- **决策过程**：记缺——议会（Državni zbor）立法过程数据不在公报源内，未采。
- **版本序列**：PISRS 有原生版本序列（非官方编纂文本库 NPB，按"基本法 + 截至某次修订"双参数编址，168,368 页，2026-10-12 计）——与公报时间序列不同构，暂未采，需要时另立源。

## 2. 共享访问准备

- **数据目录**：默认 `{data_root}/SVN_policy/`（账本 `state.db` + `01_raw/` 原始层）。
- **密钥**：无——PISRS 公开接口免 key，`.env` 无需条目。
- **命令习惯**：一切命令在仓库根执行 `python cli.py <command> --country svn --source uradnilist …`（见各源文档 §6 的可复制命令）。
- **限速节奏**：框架统一限速即可；PISRS 无公开限额、实测零拦截（2026-10-12 连续上百请求）。

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
