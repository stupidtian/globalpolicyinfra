# 波兰（POL）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `isap` | **Dziennik Ustaw**（法律公报，波兰宪法规定的规范性文件法定公布刊物）：法律、条例、经批准的国际条约、宪法法院判决、编纂文本（tekst jednolity），1918–2026 全年份可枚举 | **api.sejm.gov.pl**——波兰众议院（Sejm）运营的官方 ELI API，免 key、无会话、OpenAPI 文档齐全 | [isap-zh.md](./isap-zh.md) |

ISAP（Internetowy System Aktów Prawnych，波兰法律文书系统）是这套语料的本体系统，条目内部编号（`WDU…`）即其编址；数据采集走的是它的机器接口 api.sejm.gov.pl。**isap.sejm.gov.pl 网页站受 Imperva WAF 保护且 robots 对非搜索引擎全禁，不可作为程序访问通道**（2026-09-20 实测）。

## 1b. 三结构现状

- **时间序列**：✅ 每条目三个原生日期分开收——公布日（promulgation）、公告/签署日（announcementDate）、施行日（entryIntoForce），另有数据变更时间戳（changeDate）；类型、发布机关、语言（pol）、正文文件、可重建 source_url 齐全。
- **决策过程**：— 未收（Sejm 议会法案过程系统为另一来源，未开）。
- **版本序列**：✅ 原生——每次编纂（tekst jednolity）以一份公报公告（Obwieszczenie）的形式出版，公告自带位次、公布日与编纂全文，并回链原法；采集按原法→历次公告自动展开，文档经 entity_ref 挂靠原法，一条查询即得"一部法的全部文本状态"。

## 2. 共享访问准备

- **密钥**：无需任何 key，`.env` 零条目（2026-09-20 实测）。
- **会话/反爬**：API 无应用级会话、无验证码；响应头中的负载均衡 cookie 由传输层自动处理。**限速遵守框架默认节奏**（0.5–1 秒/请求）——`/eli/changes/acts` 在不带必填参数时会被负载均衡规则以 403 拒绝，属速率类规则而非鉴权。
- **网络前提**：波兰部分政府站点（dziennikustaw.gov.pl、dane.gov.pl）对部分网络不可路由；api.sejm.gov.pl 全球可达。所在网络到 api.sejm.gov.pl 不通时，设 `HTTPS_PROXY` 走代理即可（传输层原生识别该环境变量）。
- **命令习惯**：全部操作在仓库根目录以 `python cli.py …` 执行。

| Monitor Polski（M.P.，总理署名第二刊） | 未收：只载非规范性政府文件（政府声明、任免等），无法规；同一 API 天然支持，将来需要时另立一源 |

| 1918–1989 深历史年份 | API 可枚举，但文本覆盖率与质量未逐年核验；全量回填时逐窗口验收 |
