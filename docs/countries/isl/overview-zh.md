# 冰岛（ISL）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `stjornartidindi` | 官方公报 Stjórnartíðindi 全部公布事件：法律（A deild）、行政条例（B deild，含市政条目可选）、官方公告（C deild）；2001 年起全量，1995–2000 年稀疏 | `api.stjornartidindi.is`（官方公报 API，免 key，OpenAPI 3.0） | [stjornartidindi-zh.md](./stjornartidindi-zh.md) |

制度背景一句话：冰岛的法定公布媒介就是公报本身（2005 年第 15 号法；公布的效力绑定电子版），法律与行政法规都在公报发布——一个源覆盖全国政策出台事件。现行条例的整并文本另有司法部的 Reglugerðasafn（信息性，公报优先，暂未收录，见各源文件第 8 节）；议会过程数据在 Alþingi（althingi.is，自动化 HTTP 访问被拦截，暂未收录）。

## 1b. 三结构现状

- **时间序列**：由 `stjornartidindi` 承担——每个公布事件一行 documents，公布日为主轴，签署日/入系统日分开收（生效日无结构化字段，缺失已记档）。
- **决策过程**：记缺——议会审议过程（Alþingi þingskjöl）因站点自动化访问被拦（HTTP 403）未采集。
- **版本序列**：记缺——公报 API 无原生版本谱系（条目 = 一次性公布事件）；现行条例整并文本通道（Reglugerðasafn）缺枚举入口，暂未收录。

## 2. 共享访问准备

- **无需任何 API key**（`.env` 无需本源配置）；全部通道匿名 HTTP，无反爬、无会话。
- 数据目录由框架按 `{数据根}/ISL_policy/` 组织（state.db 账本 + 01_raw 原始层）。
- 限速：建议保持框架默认 0.5–1 秒间隔（`collect --delay 0.5:1`）；公报 API 为国家开放数据接口，列表单页上限 100 条。
- 语料语言：冰岛语（`isl`）。

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 市政条目 | 源站有（B deild），默认 scope=state 过滤，`scope=all` 可补 |
| Reglugerðasafn 现行条例整并文本 | 通道存在但无枚举入口，暂未收录（另议立项） |
| Alþingi 议会过程与 lagasafn 汇编 | 站点 403 拦截，需浏览器通道，暂未收录 |
| 1995 年前公报 | 仅扫描件（timarit.is 等历史文库），无机器通道 |
| 判例（Hæstaréttardómar） | 非本框架对象 |
