# 立陶宛（LTU）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）；九节写作结构见 [_template-zh.md](../_template-zh.md)。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `tad` | 国家层级法规（2014 前《Valstybės žinios》公报时期 + 2014 后 TAR 登记时期），默认四层：议会法律/法典/宪法类、总统令、政府决议、部委令——每份带采纳日/公布日/生效日与全文 | 议会文档系统三层无状态接口：老检索枚举（www.lrs.lt）→ 文档详情（showdoc 跳转 e-seimas.lrs.lt）→ `/rs/` 原始文本服务（免 key、无会话、无浏览器） | [tad-zh.md](./tad-zh.md) |

## 1b. 三种数据结构现状

- **时间序列**：✅ 由 `tad` 源承担——每份文档带采纳日 / 公布日 / 生效日三个日期，公布媒介字段自明（2014 前《Valstybės žinios》期号、2014 后 TAR 期号与登记号）。
- **决策过程**：未收——议会的法案过程数据（法案项目、委员会结论、表决）在新门户有入口但未开工，记缺。
- **版本序列**：未收——汇总版（suvestinė redakcija，编纂文本）的机器通道已确认存在（2026-09-15 实测），需要时另立源，清单见 [tad-zh.md](./tad-zh.md) §9。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `python cli.py init` 配置，或 `POLICY_DATA_ROOT` 环境变量；立陶宛数据落在 `{data_root}/LTU_policy/` |
| 密钥 | **无需任何 key**，`.env` 不需要条目 |
| 通用命令习惯 | `collect`（key=value 传参）/ `status` / `export` / `requeue` / `reset`，全部在仓库根目录 `python cli.py` 运行 |
| 节奏 | 框架统一限速（请求间隔 0.5–1 秒随机）+ 错误三分法重试；典型一天四层切片共 8 个枚举请求 + 文档级详情与文本各一次（部令工作日约 16 条/天） |
| 语言 | 数据为立陶宛语（`lit`）；枚举层响应 windows-1257 编码、门户与文本服务 UTF-8，解析器内置回退，调用方无感 |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| TAR 本体（e-tar.lt） | 整站在 Cloudflare 浏览器校验后（2026-09-15 实测），程序化 HTTP 不可达；TAR 合同制数据服务需签约。本库以议会镜像库替代（文档带 TAR 登记号可对账） |
| 其他发布机构的规范性类型码 | 部委令（Įsakymas=37）已入默认切片；部令之外的其余机构文书类型（结论书、章程、通知等约 130 项）未采集，需要时经类型码切片扩展 |
| 汇总版/版本序列（suvestinė redakcija） | 机器通道已确认，未开工（见 1b） |
| 议会决策过程（法案项目、表决） | e-seimas 新门户有入口，未开工 |
| 地方自治体规章 / 判例 | 不在目标内（TAD 本就不含） |
| 开放数据门户 data.gov.lt | 接口服务器错误 + 站点防火墙拦截程序化访问（2026-09-15 实测），不可用 |
| 官方译文版（英文等） | 文档库内含英文译文，未单独收录 |
