## 1b. 三结构现状

- **时间序列**（必答）：已覆盖——AS 层为**公布事件本体**（每件法律在官方汇编的刊登即一条数据，公布日为时间轴主日期），制定日/公布日/生效起止四类原生日期分列全收；1848 年起事件序列完整，其中 **1998-09-01 起有数字正文文件**（电子汇编起点，此前为纸质时代，平台只存元数据——该段"发布了什么"完整、"正文文件"记缺）。
- **决策过程**：记缺——议会过程文件在《联邦公报》（Bundesblatt / Feuille fédérale，162,252 件，2026-09-09 实测），是另一层出版物，未采；法案→法律的关联字段（basicAct 等）已随条目无损保留。
- **版本序列**：**原生覆盖**——SR 层每部法一条目、每个整合时点一版本（生效窗口原生给出），条目谱系全收；正文文件按"锚点版"口径（每部法最新适用的整合版），全史时点版为可选参数。

## 2. 共享访问准备

- **无需 API key**（`.env` 空配置即可）；无会话、无浏览器，HTTP 直连。
- **数据目录**：`{data_root}/CHE_policy/`（state.db + 01_raw/fedlex/ + failures/）。
- **限速节奏**：查询端点对连续快速请求会**瞬时断开连接**（无状态码，分钟级自动恢复，2026-09-09 实测）——保持 3 秒以上间隔安全，命令行统一 `--delay MIN:MAX` 可调。
- **多语言**：联邦四种官方语（德/法/意/罗曼什）。AS 层每件法律严格三语并行（德/法/意，2026-09-09 全量实测罗曼什与英语计数为 0）；SR 层版本另含罗曼什/英语（仅部分条目）。本源三语（及以上）**全收**，见源文件 §4 的多语言口径。
- **两个域名的分工**：查询走数据域（fedlex.data.admin.ch），文件下载走门户域（www.fedlex.admin.ch）——门户域对自动化访问全放行，数据域的文件库路径在 robots 声明中不让抓（2026-09-09 实测），故下载一律走门户域同路径。
