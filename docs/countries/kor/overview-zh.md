# 韩国（KOR）数据源总览

> 一个源一个文件：本文件只做总览与共享信息，各源细节见对应文件。
> 文件命名规则：`{iso3}/{source}-{lang}.md`（国家文件夹 + 语言后缀，lang ∈ zh/en）；九节写作结构见 [_template-zh.md](../_template-zh.md)。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| `lawgokr` | 现行法规库（현행법령）：当前有效的宪法、法律（법률）、总统令/总理令/部委令（령）、各宪法机关规则——官方 2026-08-12 口径 5,605 条，**一个名录混排立法与行政两系统**；含每部法规的全部历史版本正文与官方修法理由（生命线数据） | [www.law.go.kr](https://www.law.go.kr)（법제처 运营的국가법령정보센터）表单接口，GET 直连、免 key 免会话 | [lawgokr-zh.md](./lawgokr-zh.md) |

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `python cli.py init` 配置，或 `POLICY_DATA_ROOT` 环境变量；韩国数据落在 `{data_root}/KOR_policy/` |
| 密钥 | **无需任何 key**，`.env` 不需要条目（姊妹站 open.law.go.kr 的官方 Open API 需 OC key，现行法规库源不用它） |
| 通用命令习惯 | `collect`（key=value 传参）/ `status` / `export` / `requeue` / `reset`，全部在仓库根目录 `python cli.py` 运行 |
| 节奏 | 框架统一限速（请求间隔 0.5–1 秒随机）+ 错误三分法重试；现行法规库全量约 6,732 行名录（135 页）+ 每法规版本链 |
| 语言与编码 | 全韩文，端点全 UTF-8；Windows 控制台（cp936）打印韩文会乱码，看数据请用 `export` 或直接读库 |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 행정규칙（行政规则，훈령·예규·고시等） | 独立语料独立端点（约 149K 条），端点与参数已探明，候选扩展源（见 lawgokr-zh.md §8/§9） |
