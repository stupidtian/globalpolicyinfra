# 智利(CHL)数据源总览

> 一个源一个文件:本文件只做总览与共享信息,各源细节见对应文件。
> 文件命名规则:`{iso3}/{source}-{lang}.md`(国家文件夹 + 语言后缀,lang ∈ zh/en)。

## 1. 源清单

| 源 | 覆盖什么 | 数据从哪来 | 说明文件 |
|---|---|---|---|
| leychile | 全国规范性文件(法律、政令、决议、条例等),1850 年至今,含已废止者;每部法规的全文与全部历史版本 | Ley Chile(国会图书馆 BCN 运营的法律数据库)的 JSON 查询接口 | [leychile-zh.md](./leychile-zh.md) |

## 1b. 三结构现状

- **时间序列**:由 leychile 源承担——全库 415,344 部(2026-09-20 实测),按公布日排列完整序列,制定日/公布日/生效日/废止日四类原生日期字段分开收录。
- **决策过程**:本源没有(议会立法过程不在其范围);已探明国会侧接口存在,属后续源(见 leychile-zh.md 第 8 节)。
- **版本序列**:leychile 原生支持——每部法规的历次修订版本与文本快照(见对应文件第 3 节)。

## 2. 共享访问准备

| 项 | 说明 |
|---|---|
| 数据目录 | `{data_root}/CHL_policy/`(state.db 与全部原始文件在此之下) |
| API key | **不需要**(`.env` 零条目) |
| 语言 | 西班牙语(`spa`) |
| 限速 | 默认每请求间隔 0.5–1.0 秒(站点未观察到限流,保持礼貌) |
| 命令习惯 | `python cli.py collect --country chl --source leychile years=2024`,详见源文件第 6 节 |

## 3. 尚未覆盖的政策层

| 层 | 现状 |
|---|---|
| 官方公报(Diario Oficial)原生流 | 未覆盖——leychile 收录其规范性内容(含公报期号字段),公报中的非规范性内容(任命、公告)与逐日原件另需公报源 |
| 议会立法过程(法案、审议) | 未覆盖——接口已探明待立项 |
| 市政法规(ordinanzas municipales) | 未覆盖——在另一登记系统 |
| 法规译本(英语等) | 未覆盖——站点部分提供,未接入 |
