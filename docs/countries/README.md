# 国家总目录

> 一个国家一个文件夹（如 `usa/`），内含该国总览（`overview-zh.md`）与每源一文件。本文件是全部国家的总目录：清单、数据形态分类、三种数据结构现状、进展（粗粒度状态 + 日期；各国数据快照见其源文件文末）。

## 三种数据结构（研究需要什么，采集就供什么）

| 数据结构 | 一句话 | 采集政策 |
|---|---|---|
| **时间序列** | 一个国家按时间排出"发布了什么政策"的完整序列 | **每国强制底线**：序列完整、日期齐全（制定日/生效日/登记日分开收）、类型、发布机关、语言、正文文件、可重建的官方链接 |
| **决策过程** | 一项政策从提出到出台的过程记录（议会动作、审查、议程） | 不强求：有原生来源就收全，没有就记缺 |
| **版本序列** | 同一部法规在时间上的各个文本状态 | 不强求：同上 |

修订关系（谁修订/废止了谁）不在采集阶段建图——它的原始字段（如法国的现行法标识、澳洲的废止记录、韩国版本行的修订法令号）随源照收，建图与分析留给后续阶段。

## 源的三种形态

| 形态 | 含义 | 已有国家 |
|---|---|---|
| **公报型** | 官方公报，一次刊登 = 一条数据，颁布原样快照 | 德国、法国、西班牙、挪威、日本、阿根廷、墨西哥、瑞典、丹麦、立陶宛、拉脱维亚、冰岛、葡萄牙（期级）、巴西、哥伦比亚（diario 整期） |
| **登记册型** | 现行法规登记库，一法规一实体，原生版本谱系 | 韩国、澳大利亚、智利、英国（进行中）、哥伦比亚（suin 现行文本活视图，无版本谱系） |
| **生命周期型** | 过程数据为主（动作/阶段/审查），文档是过程的产物 | 美国 |

（多载体国按主载体归类：瑞士/波兰/奥地利为公报+编纂双载体，芬兰为登记册型开放数据——细目见各行。）
